## 5. IOC 전달 시 defang 규칙

카카오톡, 메일, 문서에 악성 IP/URL/도메인을 넣을 때 자동 링크가 걸리지 않도록 아래처럼 작성합니다.

```text
172.240.253.132   → 172[.]240[.]253[.]132
example.com       → example[.]com
https://example.com → hxxps://example[.]com
http://example.com  → hxxp://example[.]com
```

## 6. 고객사/내부 확인 요청 문구

```text

대상 프로세스는 정상 관리 스크립트로 보이나, 운영 서버의 보안 가시성 유지를 위해 예외처리 여부 검토가 필요합니다.

확인 후 예외처리 적용 여부 및 지속 모니터링 방향에 대해 회신 부탁드립니다.

감사합니다.
```
